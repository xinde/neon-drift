# Neon Drift

霓虹漂移 — 一款赛博朋克风格的 2D 迷宫漂移游戏。

[在线试玩](https://xinde.github.io/neon-drift/) · [设计文档](DESIGN.md)

## 游戏玩法

- **手机**：倾斜设备或拖动屏幕控制光球漂移方向
- **PC**：WASD / 方向键控制
- **冲击波**：空格键（PC）/ 点冲击波按钮或摇动设备（手机），清除 2.5 格内的暗礁，冷却 3 秒。拾取晶体会立即充好冲击波
- 收集全部晶体后抵达绿色光门过关。每关单独计时，个人最佳保存在当前浏览器。生命耗尽后可点击或按回车重试本关

## 开发

直接用浏览器打开 `index.html` 即可运行。

详细设计理念和维护文档见 [DESIGN.md](DESIGN.md)。
